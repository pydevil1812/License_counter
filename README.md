# License Counter Server

## Описание

Данный проект представляет собой сервер мониторинга для подсчёта общего размера и количества файлов в заданных папках, а также подсчёта количества записей во внешних SQL базах данных. Все данные доступны через REST API. Это позволяет оперативно контролировать использование дискового пространства и количество лицензий (записей), а также отслеживать превышение установленных лимитов.

---

## Основные возможности

- Рекурсивный подсчёт размера и количества файлов в указанных директориях с учётом заданных расширений.
- Подсчёт количества записей в одной или нескольких внешних базах данных через SQLAlchemy.
- Периодическое фоновое обновление данных с безопасным обновлением SQLite БД.
- REST API с многочисленными эндпоинтами для получения информации по папкам, файлам и базам данных.
- Индикация состояния — "Превышение лимита", "На грани", "В норме" в сравнении с лимитами.
- Лёгкий веб-сервер на Flask, удобный для интеграций и дашбордов.
- Гибкая настройка через переменные окружения и YAML-файл с лимитами.

## Установка

1. Клонировать репозиторий или поместить файлы проекта в одну папку.
2. Убедиться, что установлен Python версии 3.7 и выше.
3. Установить зависимости из `requirements.txt`:

## Настройка

### Файл переменных окружения `.env`

Пример содержимого:

```
PORT=3000
HOST=0.0.0.0
DB_PATH=folders.db
CYCLE=15
DISK_SPACE={"path1":"C:\\Users\\ironm\\Desktop\\DAEMON\\License_counter\\test", "path2":"C:\\Users\\ironm\\Desktop\\DAEMON\\License_counter\\end"}
DB={"name1":{"uri":"sqlite:///folders.db","table":"folders"}}
FILE_EXTENSIONS=doc,docx,dotx,docm,xls,xlsx,xlsm,ppt,pps,pptx,ppsx,pptm,ppsm,rtf,txt,html,htm,odp,ods,odt,xml,pdf,tiff,tif,eml,msg,zip,rar,tar,gz,7z,vsd,vsdx
```

- `PORT` — порт, на котором будет работать сервер.
- `HOST` — адрес, на котором сервер будет принимать запросы.
- `DB_PATH` — путь к локальной SQLite базе для хранения статистики.
- `CYCLE` — интервал обновления мониторинговых данных (в секундах).
- `DISK_SPACE` — JSON-словарь с ключами-именами и путями папок для мониторинга.
- `DB` — JSON-словарь с параметрами внешних баз (`uri` для подключения и `table` для подсчёта записей).
- `FILE_EXTENSIONS` — список расширений файлов, которые будут учитываться при подсчёте.

---

### Файл лимитов `license_count.yaml`

Формат:

```
limit_size: 10          # Лимит по размеру в ГБ
limit_files: 10000      # Лимит по количеству файлов
limit_dashboards: 5000  # Лимит количества записей в базе данных
edge_percent: 80        # % значения лимита для статуса "На грани"
```

Эти параметры определяют пороги для статусов, возвращаемых API.

## Запуск сервера

Запустите сервер командой:

```
python license_counter.py
```

Сервер начнёт работать на адресе и порте, указанном в `.env`, обновляя данные каждые `CYCLE` секунд в фоне.

## REST API

### Основные эндпоинты:

| Метод | URL                         | Описание                                            |
|-------|-----------------------------|-----------------------------------------------------|
| GET   | `/api/size`                 | Размеры папок (МБ), общий размер, лимиты, статус    |
| GET   | `/api/size/<name|total>`    | Размер конкретной папки или общий размер            |
| GET   | `/api/filenum`              | Количество файлов по папкам, итого, лимиты и статус |
| GET   | `/api/filenum/<name|total>` | Количество файлов в папке или итого                 |
| GET   | `/api/count`                | Количество записей в базе(ах), лимиты и статус      |
| GET   | `/api/count/<db_name>`      | Количество записей в конкретной базе                |
| GET   | `/api`                      | Полная сводка по размерам, файлам и базам           |

### Статусы

- **Exceeding the limit** — превышение лимита.
- **On edge** — граница лимита (наступает при достижении `edge_percent` от лимита).
- **All right** — в пределах нормы.

## Внутреннее устройство

- Используется SQLite база `folders.db` для хранения информации о размерах и количестве файлов.
- Периодическое обновление данных в фоне через поток.
- Подсчёт статистики по файлам учитывает только расширения из `FILE_EXTENSIONS`.
- Работа с внешними базами через SQLAlchemy для подсчёта количества записей.
- Flask + Flask-RESTful организуют API.
- Логирование ошибок и состояния обновления.
