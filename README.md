# License_counter

## Назначение

Сервер мониторинга, который следит за объёмом папок, количеством файлов и числом записей во внешних SQL-базах. Он регулярно обновляет статистику, сравнивает её с лимитами и отдаёт сводку через REST API.

## Возможности

- рекурсивный подсчёт файлов и их размера по заданным расширениям;
- подсчёт записей в подключённых базах через SQLAlchemy;
- фоновые обновления с сохранением статистики в SQLite;
- статусы «в норме», «на грани» и «лимит превышен»;
- REST-эндпоинты для размеров, количества файлов, баз и общей сводки;
- настройка через `.env` и `license_count.yaml`.

## Запуск

Создайте `.env` по образцу из документации, не добавляя реальные пути и параметры доступа в Git:

```bash
pip install -r requirements.txt
python license_counter.py
```

После запуска API доступно по адресу и порту из переменных `HOST` и `PORT`. Основные маршруты: `/api`, `/api/size`, `/api/filenum` и `/api/count`.

## Технологический стек

- Python
- Flask и Flask-RESTful
- SQLAlchemy
- SQLite
- PyYAML и python-dotenv

## Статус и ограничения

Проект делает полезную диагностику инфраструктуры, но ему нужны аккуратные права доступа к папкам и базам. Реальные секреты и строки подключения должны находиться только в локальном `.env`; перед эксплуатацией стоит добавить аутентификацию API и тесты на ошибки подключения.
