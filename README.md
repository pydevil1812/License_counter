# License Counter

**License Counter** — серверное Python-приложение для мониторинга размера и количества файлов в указанных папках, а также получения статистики по базе данных через REST API.
Протестированно на операционных системах Windows 10 и Ubuntu 24.04.2

## Возможности

- Подсчет общего размера и количества файлов в заданных директориях.
- Хранение информации о папках в базе данных SQLite.
- REST API для получения информации о размерах, количестве файлов и статистике по базе данных.
- Автоматическое обновление данных с заданным интервалом.

## Установка

1. Клонируйте репозиторий или скачайте файлы проекта.
2. Установите зависимости:
   ```sh
   pip install -r requirements.txt

## Настройка

Отредактируйте файл `config.yaml` для указания путей к папкам, параметров базы данных и настроек сервера.

Пример:
disk_space: 
  path1: "C:/Users/ironm/Desktop/test" 
  path2: "C:/Users/ironm/Desktop/end"

cycle: 15

port: 3000 
host: '0.0.0.0'

db_path: "folders.db"

db: 
  name1: 
    uri: "sqlite:///folders.db" 
    table: "folders"

## Запуск

Для запуска сервера выполните: 
    python license_counter.py

## API Эндпоинты

- GET /api/size — размеры всех папок
- GET /api/size/<str> — размер папки по имени или total для суммы
- GET /api/filenum — количество файлов во всех папках
- GET /api/filenum/<str> — количество файлов по имени папки или total для суммы
- GET /api/count — статистика по всем базам данных
- GET /api/count/<str> — статистика по конкретной базе
- GET /api — сводная информация (размеры, количество файлов, статистика БД)

## Структура проекта

- License_counter.py — основной скрипт сервера
- config.yaml — конфигурационный файл
- requirements.txt — зависимости
- folders.db — база данных SQLite (создается автоматически)
